# Kakubal Vishwanath Saikrishna Portfolio

A production-ready personal portfolio website built with React, Vite, React Router, and modern custom CSS.

## Features

- Responsive two-page portfolio using `HashRouter`
- Sticky navigation with active route styling
- Professional hero, about, research interests, skills, education, and project sections
- GitHub Pages deployment workflow through GitHub Actions

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`

## Deployment

Push the `main` branch to GitHub and enable GitHub Pages with the **GitHub Actions** source. The workflow in `.github/workflows/deploy.yml` will build and publish the site automatically.
